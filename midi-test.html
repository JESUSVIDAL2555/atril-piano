Todavía sin conectar.

Cómo hacer que la tablet vea el teclado

  1. Cable: adaptador OTG (USB‑C macho → USB‑A hembra) + cable USB A‑B (tipo impresora) al puerto USB TO HOST del E463. Un cable de carga normal no sirve.
  2. Enciende el teclado antes de conectarlo.
  3. Baja la barra de notificaciones de Android, toca la notificación de USB y elige «USB controlado por: este dispositivo». No elijas «MIDI» en «Usar USB para»: eso convierte la tablet en el periférico.
  4. Si Android pregunta qué app usar con el dispositivo USB, acepta.
  5. Vuelve aquí, recarga y toca Conectar. Debe aparecer un nombre como «Digital Keyboard» o «Yamaha».
